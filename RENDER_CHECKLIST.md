## ✅ Deployment Steps

### Pre-Deployment
1. [ ] Run `setup-render.bat` (Windows) or `./setup-render.sh` (Linux/Mac)
2. [ ] Push code to GitHub repository
3. [ ] Ensure repository is public or connected to Render

### Render Setup
1. [ ] Create Render account
2. [ ] Create new Web Service
3. [ ] Connect GitHub repository
4. [ ] Set Dockerfile path to `./Dockerfile.render`
5. [ ] Choose free plan
6. [ ] Deploy

### Post-Deployment
1. [ ] Test health endpoint: `https://your-app.onrender.com/health`
2. [ ] Test frontend: `https://your-app.onrender.com/`
3. [ ] Test API: `https://your-app.onrender.com/api/`
4. [ ] Create admin API key
5. [ ] Test email validation functionality

## ⚠️ Free Tier Limitations

### Known Limitations
- [ ] App sleeps after 15 minutes of inactivity
- [ ] 512 MB RAM limit
- [ ] Shared CPU resources
- [ ] No persistent storage (SQLite resets on redeploy)
- [ ] No custom domains on free tier

### Workarounds
- [ ] Use external service to ping app every 10 minutes
- [ ] Consider upgrading to paid plan for production use
- [ ] Use Render PostgreSQL for persistent data

## 🔧 Troubleshooting

### Common Issues
- [ ] Build fails: Check Dockerfile.render and dependencies
- [ ] App won't start: Check logs and environment variables
- [ ] Frontend not loading: Verify static file serving
- [ ] Database issues: SQLite is ephemeral on free tier

### Debug Commands
```bash
# Test local build
docker build -t test .

# Test local run
docker run -p 8000:8000 -e PORT=8000 test

# Check container logs
docker logs <container_id>
```
